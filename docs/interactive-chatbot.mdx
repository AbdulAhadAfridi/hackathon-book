# Interactive RAG Chatbot

This page demonstrates the RAG Chatbot component that allows you to ask questions about the book content and receive answers from the RAG system.

<RAGChatbot />

## How It Works

The RAG Chatbot component:

- Captures your questions about the book content
- Sends them to our backend RAG system
- Receives grounded responses based on the book content
- Displays the answers with proper citations

Try asking questions about humanoid robotics, AI systems, or any other topics covered in this book!
